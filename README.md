# 股见 · A 股持仓分析

React 19、TypeScript、Vite、Tailwind CSS 4、Zustand 与 ECharts 实现的投资组合分析工具。持仓保存在浏览器，基本面和 AI 通过 Node 服务或 Cloudflare Worker 获取。

## 运行

需要 Node.js 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。开发与 `npm run preview` 均包含研究 API。生产使用 `npm run build` 后执行 `npm start`，默认打开 `http://127.0.0.1:5180`；可用 `PORT` 环境变量修改端口。生产服务读取 `.env.local`、提供静态文件与研究 API，并支持前端路由。仅托管 `dist/` 的静态网站不包含研究 API。

## 部署到 Cloudflare Workers

仓库包含 Worker 后端入口和静态资源配置，不能只上传 `dist/`。仅静态部署时，`/api/*` 可能被 SPA 回退成 HTML 首页，HTTP 状态仍是 200，部署成功也不代表接口可用。

在 Cloudflare 控制台绑定 Git 仓库后设置：

- 根目录：项目根目录（`/`）。
- 构建命令：`npm run build`。
- 部署命令：`npx wrangler deploy`。
- Worker 名称：`a-share-dashboard`，与 `wrangler.jsonc` 一致。

先提交并推送本次变更（包括 `worker/`、`server/`、`.agents/skills/`、`wrangler.jsonc` 和依赖锁文件），再对最新提交触发部署。不要使用仅发布静态目录的部署方式。CLI 发布也可执行 `npm run deploy`（先用 `npx wrangler login` 登录）。

`wrangler.jsonc` 用 Fetch 入口处理全部 `/api/*`，由 `ASSETS` 提供前端页面及 SPA 路由。三份 Skill 文件以文本模块打包进 Worker；编辑后需要重新部署。开启 `nodejs_compat` 兼容现有服务逻辑，无需在 Cloudflare 上运行 `npm start` 或常驻 Node 进程。

部署后检查以下地址，不能只看首页：

- `/market`：前端页面。
- `/api/ai/config`：200、`application/json`，包含两个服务商；未填写用户密钥时 `configured: false` 正常。
- `/api/research/skills`：200 JSON，包含三种研究流程。
- `/api/not-found`：404 JSON，不能返回 HTML。
- `/api/market`：盘面 JSON；若为 502 JSON，说明后端已运行，但行情源连接失败，需另查数据源可达性。

本地验证 Worker：`npm run dev:worker`。仅检查打包、不发布：`npm run check:worker`。每位用户仍在网页「偏好设置」填写自己的模型密钥，不需要在 Cloudflare 配置共享模型密钥。

## 短线盘面观察

打开 `/market`，读取东方财富公开行情。从沪深成交额前 100 以及前 4 个领涨板块各最多 30 只成分股合并筛选，不是全市场穷举。样本涨跌家数仅代表扫描范围，不能当作全市场宽度。

当前规则：排除 ST、退市标记和非沪深 A 股；价格至少 2 元、成交额至少 2 亿元；涨幅 0.5%–7.5%、量比至少 1.2、换手 1%–18%；现价至少处于日内区间的 45% 位置。同一热点或行业最多 2 只，最多展示 5 只，不为凑数放宽条件。匹配分按量比、成交活跃度、涨幅位置、换手、日内位置及热点共振加权，未经回测，不是上涨概率。

盘面缓存 60 秒，支持手动强制刷新和页面可见时自动更新。旧交易日、时间异常、刷新失败和数据缺失均有提示。服务失败时保留上一次快照并标记过期，不生成虚构股票。财报研究与 AI 仍是单独按需执行。

「加入观察」保存到独立的 `a-share-watchlist`，不会变成真实持仓。观察名单支持筛选、移除和查看公司研究；已观察股票即使离开本轮候选也可继续查看。

## 尾盘选股

导航「尾盘选股」或打开 `/tail-selection`，以项目 `yang.md` 十步法为规则参考，并遵循 `.agents/skills/` 中量价、基本面和反向风险的证据边界。`GET /api/tail-selection` 使用独立涨幅排行扫描，不从盘面页已筛选的 5 只候选二次筛选。默认读取沪深主板涨幅排行（不含创业板、科创板），可切换全部沪深 A 股；范围通过 market=main/all 传递，缓存和请求分别隔离，源查询与股票代码双重过滤。卡片标识主板 / 创业板 / 科创板，切换范围清除旧快照与复核。读取排行最多 10 页、每页请求 100 条，明确显示实际覆盖和分页失败；排除 ST / 退市标记，缺失时间及旧时点记录不混入当期样本，不宣称全市场完整覆盖。

四项数值同时满足：涨幅 3%–5%、量比 ≥1、换手 5%–10%、流通市值（f21，非总市值）50–200 亿元。界面提供指数原始时点、逐层漏斗、候选搜索、全部涨幅初筛 / 数值通过 / 本轮已观察筛选；沿用独立观察名单、公司财报和三种 Skill 研究弹窗。服务缓存 60 秒并合并并发，失败保留旧快照且标记过期；支持手动强刷与可见页面 60 秒自动刷新。Node、Vite、Worker 共用 API 实现。

大盘历史趋势、成交量形态、K 线、分时均价线、尾盘触发及财务公告风险均需人工核实，单次行情快照不自动判定通过。复核记录在当前页面内存中，刷新数据后清除；可连同行情与 demo 标识导出 JSON。演示使用虚构数据，不能加入真实观察名单或运行真实公司研究。时间窗口按北京时间显示，周末和历史 / 延迟数据仅供复盘，没有自动交易信号或下单功能。

策略说明列出原文仓位与时间的冲突：使用单票 ≤20%、单日最多 3 只、不满仓的保守口径；保留 14:50–14:58 窗口并提醒排除 14:55 后突击拉涨。涨停历史与热点关系标为额外待查项，未用不存在的数据补齐。

## 竞价选股

打开 `/auction`（导航「竞价选股」），支持四项同时满足：前一交易日收盘价等于实际涨停价；09:15:00 竞价价等于今日实际涨停价；09:25:00–09:25:05 内最新一笔价格严格大于 09:24:57 价格；09:25 最终竞价成交量 / 前一交易日全天成交量严格大于 3%，或最终竞价成交额严格大于 1 亿元。量占比与成交额阈值可修改，点击「应用条件」重新筛选。

固定增加两项过滤：排除创业板（深圳 30 开头，包含 300/301）和名称带 ST、*ST 等风险警示标识的股票；09:25 最终竞价价须不低于昨收，涨幅为负的股票不入选，0% 平开保留。缺少昨收或最终竞价价时标为待核验。统一筛选逻辑应用于自动取数、手动快照、演示及导出名单，逐股核验提供排除原因，结果表显示竞价涨幅；漏斗最后一步反映附加过滤后的实际入选数量。

进入页面即请求 `GET /api/auction` 自动取数：东方财富 `getYesterdayZTPool` 提供昨日涨停池及其确认依据，实时行情提供今日实际涨停价与行情日期，未复权日线提供前一交易日全天成交量，分笔接口 `details/get?pos=0&iscca=1` 提供含竞价的精确秒级数据。精确读取 09:15:00、09:24:57；最终竞价取数窗口为 09:25:00–09:25:05（含两端），取窗口内最新一笔且价格、成交量来自同一笔，窗口外数据不补齐。`price092500` 字段保留兼容旧文件，`auctionTime` 记录实际采样时间（旧快照可省略）；最终价格还须与同日开盘价一致。分笔及日线成交量由手乘 100 换算为股，竞价成交额按最终竞价价格 × 成交股数计算，不使用全天成交额。涨停池确认通过 `previousLimitUpVerified` 保留，不反推昨日涨停价。扫描仅覆盖源池中的沪深 A 股，不含该池未覆盖的 ST、科创板和未开板新股，非全市场穷举。最大 500 只，5 只股票并发、请求失败重试一次，缓存 60 秒、合并并发；刷新按钮支持强制更新。Node、Vite 与 Cloudflare Worker 共用同一实现，无 Python 常驻服务或 API Key 依赖。

指数未复权日线确定前一交易日；源池日期须与基准行情日期一致。分笔自身不携带交易日期，通过同期个股行情日期、分笔昨收与未复权日线交叉核验，不支持任意历史日期回溯。休市或源时间滞后时明确标记，刷新失败保留上次快照并标记过期。部分股票源时间戳可能整体偏移一秒，09:15:00、09:24:57 仍须精确匹配，09:25 最终快照仅允许上述五秒窗口。页面可见且处于自动模式时每 60 秒更新，开启自动更新时于 09:25:05 额外强制取数，后端同时失效窗口结束前的缓存；切换演示、导入、清空均停止自动更新，点击「刷新竞价」恢复。

也可下载空白 JSON 模板、校验预览并导入单日最多 6000 条沪深 A 股记录，或主动加载明确标注的虚构演示。手动快照仅保存在页面内存中，离开或刷新后恢复自动取数。成交量必须换算为股，成交额为元，价格最多两位小数；零成交与缺失 null 分开处理。手动文件的竞价日、前一交易日和精确时点由供应商声明，页面不替代供应商交易日历与采样精度核验。

缺失关键数据且没有已知失败的股票显示「待核验」，已知不满足任一条件显示「未通过」；第 4 项任一分支通过即可满足该项。支持逐股核验、缺失原因、状态分类、名称代码搜索、筛选漏斗、入选快照 JSON 导出。演示导出保留 demo 标识，重新导入仍标为演示。旧日期标注历史快照，样本统计不代表全市场。运行 `node scripts/check-live-auction.mjs` 可实测源接口并保存 `test-results/live-auction.json`。

## 入选股票后续表现

从竞价页点击「回测入选股票」，或打开 `/auction/backtest`。直接带入已经入选的股票和日期，不要求再次提供 09:15 / 09:24:57 历史报价。自动快照在 09:25:05 起且日期有效、未过期时，将入选名单保存到当前站点的 `localStorage`（`a-share-auction-selections-v1`）。同日同阈值合并，阈值不同隔离；完整名单不会被后来的不完整快照覆盖，演示及竞价未完成快照不保存。只在页面实际打开并完成取数时记录，不在后台采集；更换浏览器/端口或清理站点数据会影响记录，可导出备份。

`GET /api/auction/performance?code=SZ002843&date=2026-11-18` 自动读取指定入选日的新浪历史成交分笔（升序首屏），与该日东方财富未复权日线开盘价交叉核验后，取 09:30 后连续交易首笔。指数实际交易日历确定次一交易日；仅该日已收盘并且有个股日线才生成卖出价。今日盘中不将当前日线 close 当成最终收盘；首笔缺失不以 09:25 竞价成交或日线开盘价补齐。接口合并并发、缓存 60 秒并支持 `refresh=1`，前端每批最多 2000 条、3 条并发，显示每条缺口。2026-11-18 实测泰嘉股份 09:30:00 首笔 16.77 元，次一交易日尚未收盘，保留等待状态。

界面提供入选日、股票、买入参考价、次日收盘价、最新价、每 100 股含费价格测算及浮盈亏。浮盈亏扣买入费用但不提前扣未来卖出费；已完成样本使用佣金万 2.5（最低 5 元）、过户费万 0.1、卖出印花税万 5、单边滑点万 10。这个每手样本合计不是组合资金收益或年度策略回测；次日涨跌停成交能力、成交量参与约束和除权分红尚未完整核验。缺失数据不计作零收益。

历史入选名单支持原「导出入选」文件，或 `{"schemaVersion":1,"kind":"auction-selections","days":[{"tradeDate":"2026-11-17","source":"真实历史名单来源","rules":{"volumePercent":3,"amountYuan":100000000},"complete":true,"stocks":[{"code":"SZ002843","name":"泰嘉股份","limitUpPrice":17.34}]}]}`。示例仅说明格式，不声明该股在示例日期真实入选。只需已知入选股票，不需要全候选池或原始竞价字段；complete 表示名单经来源确认完整，未知应写 false；完整零入选日可以用空 stocks。缺少过去每天的入选记录时，不能将今天名单冒充历史信号或输出真实年度盈亏。历史分笔也可能缺失，逐项显示原因。

## 完整历史条件及交易档案回放

此前的严格回放保留在 `/auction/strategy-backtest`，用于从原始历史竞价档案重建策略及组合资金流，与上面的入选后价格跟踪分开。`GET /api/auction/backtest/coverage` 从上证指数日线取得最近一年实际交易日历，缓存 10 分钟，支持 `?refresh=1`。

**目前没有可运行原策略一年回测的历史竞价源，尚未生成真实年度盈亏。** 2026-11-18 实测区间为 2025-11-18 至 2026-11-17，共 242 个交易日。东方财富 `details/get` 传入 20251118、20261021 两个历史日期仍返回相同的当日竞价数据，且不携带历史交易日期。新浪近期历史分笔从 09:25 成交开始，缺少 09:15 和 09:24:57 的指示报价。Tushare `stk_auction_o` 文档的开盘竞价成交汇总没有所需的两个精确报价时点，不能直接替代。运行 `node scripts/check-backtest-data.mjs` 可复核当前接口并保存原始响应至 `test-results/backtest-data-check.json`。不同日期返回相同快照不意味着历史策略每天选中相同股票。

回测引擎支持导入完整历史 JSON 档案（最多 25 MB、400 日），并检查日历覆盖、历史完整候选池、当时名称、缺失竞价条件、成交及每日估值。缺少任何必要数据时只输出缺口清单，不输出年度收益，也不把缺失日当零交易。空白模板的 `poolComplete` / `historicalNames` 均为 false，必须由真实历史数据确认后填写。单日竞价文件不能直接用于全年回测。档案仅在当前页面内存中使用，刷新后清除。

已确认交易规则：09:30 后连续交易阶段首个可成交分笔价买入，次一交易日收盘卖出。默认 100 万本金，每天新买预算为前一日总资产 50% 且不超过早盘现金；多只股票按代码升序取前 5 只、等额分配，已有持仓不重复买入。整百股下单，科创板至少 200 股。默认参与首笔成交量不超过 10%；首笔涨停或买入滑点价超涨停时跳过。下午卖出所得不回填当日早盘预算。停牌或收盘跌停时延后卖出；期末持仓按最后收盘估值，浮盈亏与已实现分列，不强行清仓。分笔价格是模拟依据，不能证明实际订单成交。

默认双向佣金万 2.5（每笔最低 5 元）、卖出印花税万 5、双向过户费万 0.1、单边滑点万 10，均可修改。买入滑点价向上取分、卖出向下取分；费用逐次舍入到分。结果提供总盈亏、总收益率、每日收盘最大回撤、已平仓胜率、已实现/浮动盈亏、费用、资金及回撤曲线、逐笔盈亏、未买入原因及 JSON 报告导出。修改参数会清除旧结果。演示档案及报告保留 demo 标识。最大回撤包含初始本金，不含盘中回撤，浮盈亏不预扣尚未发生的卖出费用。

历史档案格式：

```json
{
  "schemaVersion": 1,
  "kind": "auction-backtest",
  "source": "真实历史供应商名称",
  "scope": "逐日完整昨日涨停候选池范围，包含当时股票及名称",
  "days": [{
    "date": "2026-11-18",
    "previousTradeDate": "2026-11-17",
    "poolComplete": false,
    "historicalNames": false,
    "candidates": [],
    "bars": []
  }]
}
```

`candidates` 每行使用上文单日竞价 `records` 字段，不能只给最终入选列表。确定无候选的日子可为空，未知不能宣称完整。`bars` 须覆盖入选股票以及持仓期间的每个交易日，每行包含 `code`、`close`、`limitUp`、`limitDown`（未复权元价格）、`suspended`、`corporateAction`，及 `firstTrade: { time: "09:30:00", price: 10.50, volume: 100000 }`（北京时间、元、股）；停牌可用 `firstTrade: null`。运行遇到持仓或入选股除权分红时阻止报告，当前不处理分红现金及送转股数，不能通过前复权价绕过。历史 ST 状态及候选池完整性由供应商声明，软件不能从今天的名单验证历史退市样本。

## 配置 AI

### 研究 Skill

盘面候选的「基本面与 AI 研究」提供三种项目自定义流程：`a-share-tape`（量价复核）、`a-share-fundamentals`（基本面复核）、`a-share-risk-review`（反向风险核查）。源文件在 `.agents/skills/<名称>/SKILL.md`，前端可以查看完整内容与 SHA-256 内容版本。它们是本项目编写的分析约束，不是外部认证策略，也不是行情源。

`GET /api/research/skills` 读取固定白名单 Skill；`POST /api/research/analyze` 接受代码、Skill ID、模式和模型选择；AI 模式额外携带当前用户填写的凭证。后端重新取得公开盘面与财报，不信任客户端提供的行情、持仓或指令。`checks` 模式运行固定的资料检查，不调用模型；`ai` 模式把所选 Skill 作为模型系统指令，并传入公开事实与检查结果。无密钥时仍可运行资料检查。Node 服务在下一次请求读取 Skill 新内容与版本；Worker 使用部署时打包的版本，修改后需重新部署。Skill 不改变原始选股排名。

当前没有公告正文、新闻搜索、历史 K 线或分时序列；研究中明确标记这些资料缺口。Node 生产运行需保留 `server/`、`.agents/skills/` 和 `dist/`；Cloudflare 按上面的 Worker 方式打包部署。单独部署静态 `dist/` 不能运行研究服务。

在「偏好设置 → AI 模型设置」选择 DeepSeek 或火山方舟，填写自己的 API Key 和准确的文本模型/接入点 ID，点击「保存配置」即可生效，无需改文件和重启服务。可点击「测试连接」验证鉴权与模型可调用性，测试会发送简短消息并可能消耗少量额度。

每位用户的密钥保存在当前标签页的 sessionStorage，刷新保留、关闭标签页后需重新填写，可随时按服务商清除。浏览器会话存储不是加密保险库；页面通过密码框遮挡，不将密钥写入 localStorage、导出文件或服务端磁盘。AI 请求在 JSON 正文携带该用户填写的凭证，经后端服务转发到固定的所选服务商 HTTPS 地址；后端不会将密钥放入模型提示词、响应或日志。模型配置接口仅返回服务商元信息，不返回任何密钥。原有 .env.local 中的共享模型密钥不再作为网页用户的兜底凭证。部署外网时必须使用 HTTPS。

基本面与 Skill AI 请求均使用用户当前填写的凭证；无凭证时不会回退到开发者账户。AI 仅收到服务端取得的公开财务与行情，不发送用户股数、成本或盈亏。演示模式须主动加载真实财报；不自动触发付费模型。

真实持仓保存在当前站点的 `localStorage`；行情仅保存在内存。清除浏览器数据或更换访问端口会影响已有持仓的可见性，请先导出备份。首次打开为空组合，可点击「先看看演示组合」。

## 数据边界

行业采用静态映射，支持在表单中手动指定。公开行情服务可能受跨域、网络、服务限流及延迟影响，界面会标注缺失或过期数据，相关分析视为暂估。今日盈亏按当前股数与昨收计算，不含已实现收益、交易费用与分红。零成本收益率显示「—」。

财报来自东方财富公开接口，按需读取、缓存 10 分钟，可能出现中断或字段缺失。营收、利润、现金流为报告期累计值，不能直接当作单季度数据比较；估值是采集时快照。AI 不包含联网搜索，仅依据传入公开指标，不能代替阅读完整公告或行业研究。

本地服务默认只监听 `127.0.0.1`。如需向外网部署，须另外添加身份验证与调用配额，限制请求滥用。

当前不包含券商连接、下单、真实持仓历史净值、K 线详情。竞价策略历史模拟单独提供，须先补齐历史数据。
